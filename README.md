# Sales Data Analysis Dashboard

A Python-based interactive dashboard built with Streamlit to visualize and analyze sales data for an electronics store.

## Features

- **Interactive Filtering**: Filter sales data by product category (Laptop, HP, Aksesoris) using a side panel.
- **Data Visualization**: 
  - View total revenue trends over time using interactive line charts.
  - Track product sales performance by category using bar charts.
- **Detailed Data View**: A comprehensive data table showing detailed transaction info (Date, Category, Product, Price, Quantity Sold, Total Revenue) formatted in Indonesian Rupiah (Rp).

## Technologies Used

- **Python**
- **Streamlit** (Web framework)
- **Pandas** (Data manipulation)
- **Plotly Express** (Data visualization)

## How to Run Locally

1. **Clone the repository** (or download the files):
   ```bash
   git clone <your-repo-link>
   cd Portfolio_Data_Dashboard
   ```

2. **Install the dependencies**:
   Ensure you have Python installed, then run:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app**:
   ```bash
   streamlit run dashboard.py
   ```
   The dashboard will automatically open in your default web browser.
